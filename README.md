# L7a4eg AI | لحاذگ 🇲🇷

**مساعد ذكاء اصطناعي موريتاني للهواتف والحواسيب - مصمم لموريتانيا أولاً مع التوسع لغرب إفريقيا**

---

## 📌 نبذة عن المشروع (Project Overview)
**لحاذگ (L7a4eg AI)** هو تطبيق ويب متجاوب (Mobile-First) مصمم خصيصاً لتلبية احتياجات المستخدمين في الجمهورية الإسلامية الموريتانية ودول الجوار في غرب إفريقيا. يتميز التطبيق بـ:
1. **أولوية خاصة للهجة الحسانية الموريتانية**: فهم عميق لتراكيب الحسانية، الأمثال الشعبية، الشعر الحساني (لغن)، وطقوس الضيافة والشاي (أتاي).
2. **تعدد اللغات مع الشفافية والأمانة المعرفية**:
   - الحسانية الموريتانية (Hassaniya) - دعم وأولوية قصوى [RTL].
   - العربية الفصحى (Modern Standard Arabic) [RTL].
   - الفرنسية (Français) [LTR].
   - اللغات الوطنية: البولارية (Pulaar)، السوننكية (Soninké)، الولوفية (Wolof)، والبامبارا (Bambara) - مدعومة عبر القاموس المجتمعي مع توضيح مستوى الدعم واقتراح بدائل مضمونة.
3. **أمان مالي كامل وبدون تكلفة (Zero-Cost Prototype)**:
   - يعمل التطبيق على الحصة المجانية التطويرية المتاحة لـ Gemini API.
   - لا يتطلب إدخال أي بطاقة بنكية أو تفعيل أي اشتراك مدفوع.
   - استوديو الصور والفيديو مهيآن معمارياً دون استهلاك مالي تلقائي.

## 🚀 المميزات الرئيسية (Core Features)

### 1. المحادثة الذكية (AI Chat)
- حوار ذكي وسريع باللغات الحسانية، العربية، والفرنسية.
- نماذج جاهزة لموريتانيا: ريادة الأعمال في انواكشوط، نماذج الطلبات الخطية الموجهة للولاة والحكام، نصائح مسابقات الباكلوريا والوظيفة العمومية، وشرح تطبيق هويتي.
- دعم الإدخال الصوتي (Web Speech) والاستماع الصوتي (TTS).

### 2. لحاذگ الحساني (Hassani AI)
- **مفسر الألفاظ الحسانية**: شرح معاني وأصول الكلمات الحسانية (التيفاية، كمي، أزوان...).
- **أمثال وحِكَم البيظان**: أمثال شعبية مع سياقها وحكمتها (الشور الشور، الصردة...).
- **لغن والشعر الحساني**: شرح الكاف والطلعة وأوزان وبحور لغن (لبتيت، لبير، امريميدة).
- **طقوس الأتاي والضيافة**: الجيمات الثلاث (الجماعة، الجر، والجمر)، الكؤوس الثلاثة، وآداب المجالس.

### 3. الترجمة الذكية (العربية ↔ الفرنسية)
- ترجمة دقيقة ثنائية الاتجاه مع مراعاة المصطلحات القانونية والإدارية الموريتانية.
- زر اختياري لإظهار التعبير الحساني المقابل وشروح ثقافية.

### 4. القاموس المجتمعي التشاركي (Community Dictionary)
- قاموس تفاعلي يضم كلمات الحسانية واللغات الوطنية (بولار، سوننكي، ولوف، بامبارا).
- إمكانية إضافة كلمات جديدة مع المعنى والمثال واسم المساهم.
- **مسار مراجعة وتدقيق (Review Workflow)**: يفصل المساهمات الموثقة (Verified) عن التي تحت التدقيق المجتمعي (Pending Review).
- نظام تصويت وتأييد (Upvoting) لكل مصطلح.

### 5. صانع المحتوى والتسويق (Content Creator)
- صياغة رسائل ترويجية لواتساب، سيناريوهات ريلز وتيك توك، وإعلانات فيسبوك.
- أساليب لغوية: حسانية عصرية، فصحى تسويقية، أو فرنسية.
- تخصيص للمتاجر المحلية (ملاحف ودراعات، مقاهي ومطاعم، وتطبيقات الدفع المالي مثل بنكيلي وسداد).

### 6. توليد الصور بالذكاء الاصطناعي (Image Generation)
- توليد صور حقيقية عالية الدقة مجاناً عبر محركات مفتوحة (Pollinations.ai / Flux Engine).
- خيار تحديد عدد الصور (صورة واحدة، صورتين 2 Images، أو 3 صور) بدقة ونسب أبعاد متعددة (1:1، 16:9، 9:16، 4:3).
- معاينة فورية، تكبير في شاشة كاملة، وزر تحميل مباشر للصور (Download Image).
- إلهام بصري موريتاني بنقرة واحدة (واحة ترجيت، سوق كابيتال، مكتبات شنقيط، مجالس أتاي).

### 7. توليد الفيديو التفاعلي (Video Generation)
- تحويل فكرة الفيديو أو الإعلان إلى مشاهد سينمائية متتابعة مع تعليق صوتي فوري بالحسانية أو العربية أو الفرنسية.
- مشغل فيديو تفاعلي حي (Interactive Video Player) يعتمد على محرك HTML5 Canvas مع تأثيرات الحركة السينمائية (Ken Burns)، وتكامل الصوت الموريتاني وقراءة المشاهد.
- ميزة التصدير والتحميل المباشر لمقطع الفيديو كملف WebM/MP4 إلى جهاز المستخدم فوراً.


## 🔐 نظام إدارة الحسابات والمصادقة المستقل (Standalone Custom Auth)
تم بناء نظام مصادقة يدوي ومستقل تماماً دون أي اعتماد على Firebase أو Supabase:
1. **تشفير كلمات المرور (Password Hashing)**:
   - استخدام خوارزمية `bcrypt` مع توليد أملاح عشوائية (Salts) لمنع هجمات قواميس التخمين.
   - دعم التوافق التراجعي مع دوال التشفير القياسية.
2. **أمان الجلسات (JWT & HTTP-Only Cookies)**:
   - إصدار توقيعات JWT مشفرة باستخدام `HMAC-SHA256` عبر مفتاح سري على الخادم.
   - تخزين التوكن في كعكة مشفرة `HTTP-Only Cookie` (`auth_token`) لمنع هجمات XSS.
   - دعم خيار **"البقاء متصلاً" (Remember Me)** لضبط مدة صلاحية الجلسة (30 يوماً مقابل 24 ساعة).
3. **رمز التحقق للهواتف الموريتانية (Mauritanian Phone OTP)**:
   - دعم أرقام موريتانيا عبر كود الدولة `+222` (موريتل، شنقيتل، ماتل).
   - توليد رمز سري مكون من 6 أرقام بصلاحية 5 دقائق وتتبع عدد المحاولات.
4. **مسارات المصادقة السريعة المباشرة (OAuth 2.0)**:
   - واجهات متوافقة مع Google وApple وFacebook.

## 🗄️ قاعدة البيانات وتجهيز ترحيل PostgreSQL (Database & Schema)
- يحتوي ملف `database.js` على تعريفات جداول DDL جاهزة لترحيلها إلى PostgreSQL:
  * جدول المستخدمين `users`
  * جدول رموز الهاتف `phone_otps`
  * جدول الجلسات `auth_sessions`
  * جدول التنبيهات الوطنية `notifications`
  * جدول إعدادات الإضافات `enabled_plugins`
- يعمل النظام فورياً دون الحاجة لتثبيت برمجيات خارجية اعتماداً على مستودع بيانات محلي مشفر ومحمي.

## 📱 خطة التوسعة إلى تطبيق Android أصيل (Native Android Expansion)
التطبيق مبني بتقنيات الويب الحديثة (Responsive & Mobile-First)، ومُهيأ للتحويل إلى تطبيق Android عبر أحد المسارين:
1. **Capacitor / Ionic**:
   ```bash
   npm i @capacitor/core @capacitor/cli @capacitor/android
   npx cap init "L7a4eg AI" "mr.l7a4eg.ai"
   npm run build
   npx cap add android
   npx cap open android
   ```
2. **Trusted Web Activity (TWA) / Bubblewrap**:
   تغليف التطبيق كـ PWA متطابق مع متجر Google Play مع دعم التنبيهات والعمل دون اتصال جزئي.

## 🔒 الأمان وتأكيد عدم تفعيل أي خدمة مدفوعة
- **لا توجد أي اقتطاعات بنكية**: الخادم لا يطلب بطاقة دفع.
- **مفاتيح API**: محصورة تماماً على الخادم (`server.ts`) ولا تُرسل لمتصفح المستخدم مطلقاً.
- **استهلاك الحصص**: يعتمد على الحصص المجانية القياسية لـ Google AI Studio.
